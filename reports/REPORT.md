# Отчет по практической работе № 3

## Тема

Инженерия машинного обучения. Версионирование данных и моделей.

## Цель работы

Познакомиться с организацией MLOps-процесса, автоматизировать полный цикл обучения модели, сохранять версии данных и моделей, проводить сравнение экспериментов и воспроизводить выбранный результат.

## Выбранный вариант

**Butterfly Species Classification Dataset — классификация изображений бабочек по видам.**

Так как исходный датасет не был приложен, подготовлен реальный трехклассовый набор из фотографий наблюдений GBIF/iNaturalist. Загружено по 50 изображений трех видов; для каждого снимка сохранены ссылка, авторство и лицензия. Синтетический генератор оставлен только для быстрой проверки конвейера.

## Краткие теоретические сведения

**MLOps** объединяет разработку, обучение, оценку и сопровождение моделей машинного обучения. Автоматизированный конвейер уменьшает число ручных операций и обеспечивает одинаковый порядок обработки данных при повторном запуске.

**Версионирование данных** фиксирует не только имя набора, но и его содержимое. В этой работе для исходного набора вычисляется SHA-256 по относительным именам и содержимому файлов. Для каждой версии создается снимок исходных и преобразованных изображений с манифестом: исходный файл, метка класса, вид преобразования и контрольная сумма результата.

**Версионирование моделей и экспериментов** включает сохранение сериализованной модели, параметров обучения, seed, метрик и версии данных. История дает возможность сравнивать запуски, а команда выбора восстанавливает конкретную модель из прошлой записи.

**Аугментация** создает вариации изображений с помощью отражения, поворотов и изменения цвета/яркости/контраста. Чтобы оценка не была завышена из-за попадания копий одного исходника в разные выборки, разделение выполняется до обучения, а преобразованные варианты обучающих изображений добавляются только в обучающую часть. Тестирование проводится на исходных изображениях.

## Используемые средства

- Python 3.8; Pillow — чтение, масштабирование и аугментация изображений.
- NumPy — подготовка числовых признаков.
- scikit-learn — Logistic Regression, Random Forest, SVM с RBF-ядром и метрики качества.
- joblib — сериализация моделей.
- JSONL/CSV и снимки каталогов с SHA-256 — локальная история экспериментов и данных.
- GitHub предназначен для удаленного хранения исходного кода; большие датасеты и бинарные артефакты исключены из Git.

Вместо DVC реализован компактный локальный трекер. Он покрывает требования данной работы: сохраняет версию аугментированного набора, регистрирует эксперименты и модели и позволяет выбрать любой эксперимент из истории. Для командной разработки с большим объемом данных можно перенести эти функции на DVC и удаленное хранилище.

## Этапы конвейера

1. Проверка структуры входного каталога, наличия классов и читаемости изображений.
2. Расчет SHA-256 и идентификатора исходной версии набора.
3. Стратифицированное разделение исходных изображений на обучающую и тестовую выборки.
4. Масштабирование каждого RGB-изображения до фиксированного размера и перевод пикселей в числовой вектор.
5. Создание и сохранение отдельной версии расширенного набора с манифестом и шестью типами преобразований.
6. Обучение трех классификаторов в двух режимах: исходная обучающая часть; исходная обучающая часть плюс аугментированные варианты ее изображений.
7. Оценка Accuracy, взвешенных Precision, Recall и F1 на одной и той же тестовой выборке.
8. Сохранение модели, предсказаний, отчета по классам, матрицы ошибок и параметров каждого эксперимента.
9. Просмотр истории, выбор модели по идентификатору и классификация нового изображения.

## Датасет и методика эксперимента

Использован реальный поднабор фотографий из GBIF Occurrence API для видов:

| Класс в проекте | Вид |
|---|---|
| `danaus_plexippus` | *Danaus plexippus* — monarch |
| `papilio_machaon` | *Papilio machaon* — old world swallowtail |
| `pieris_rapae` | *Pieris rapae* — cabbage white |

Скрипт `scripts/download_gbif_butterflies.py` выбирает по одному изображению на наблюдение и принимает только лицензии CC0 1.0 и CC BY 4.0. На дату загрузки, 2026-10-05, получено 50 изображений на класс (всего 150): 22 под CC0 1.0 и 128 под CC BY 4.0. Снимки скачаны в уменьшенном размере, преобразованы в RGB JPEG; контрольные суммы и сведения об авторах, правах, лицензиях и первоисточниках записаны в `data/raw/butterflies/sources.csv`. SHA-256 исходного набора: `c50679b9a1fe92cfb7d1690f125b075a07cfb77ba08b6703810541f1e92689d4`.

Данные загружены из живого API, поэтому будущий запуск скрипта может получить другой набор изображений. Текущие фотографии и манифест сохранены в рабочем каталоге, но исключены из публичного GitHub-репозитория. Манифест сохраняет атрибуцию; фотографии CC BY 4.0 при дальнейшем распространении требуют указания авторов и лицензии.

Разбиение было стратифицированным: 112 исходных изображений для обучения и 38 для теста (12 изображений *Danaus*, 13 *Papilio*, 13 *Pieris*). Seed — 42; test-size — 0.25; размер RGB-признаков — 24×24; аугментация — 3 преобразования на обучающее изображение. Аугментация выполнялась после разбиения: тест содержит только оригиналы. В снимке обработанного набора сохранено 600 файлов: 150 оригиналов и 450 преобразованных вариантов.

## Результаты на реальных фотографиях

Все модели оценивались на одной и той же тестовой выборке из 38 снимков. Для взвешенных Precision, Recall и F1 приведено значение по классам.

| Обучающие данные | Модель | Обучающих примеров | Accuracy | Precision weighted | Recall weighted | F1 weighted |
|---|---|---:|---:|---:|---:|---:|
| Исходные | Logistic Regression | 112 | 0.526 | 0.515 | 0.526 | 0.514 |
| Исходные | Random Forest | 112 | 0.447 | 0.449 | 0.447 | 0.443 |
| Исходные | SVM (RBF) | 112 | 0.395 | 0.375 | 0.395 | 0.383 |
| Исходные + аугментация | Logistic Regression | 448 | **0.605** | **0.625** | **0.605** | **0.605** |
| Исходные + аугментация | Random Forest | 448 | 0.474 | 0.466 | 0.474 | 0.469 |
| Исходные + аугментация | SVM (RBF) | 448 | 0.474 | 0.467 | 0.474 | 0.460 |

Лучший результат на этом разбиении показала Logistic Regression с аугментацией: Accuracy 0.605, взвешенный F1 0.605. F1 по классам составил 0.600 для *Danaus plexippus*, 0.593 для *Papilio machaon* и 0.621 для *Pieris rapae*. Матрица ошибок лучшей модели:

| Истинный класс \ Предсказанный | Danaus | Papilio | Pieris |
|---|---:|---:|---:|
| Danaus | 6 | 2 | 4 |
| Papilio | 2 | 8 | 3 |
| Pieris | 0 | 4 | 9 |

Вывод ограничен небольшим тестом из 38 фотографий, тремя из множества видов и простыми признаками пикселей без нейросетевой архитектуры. Метрики характеризуют только сохраненное разбиение этого набора, а не качество распознавания бабочек в общем случае. Их следует трактовать как учебное сравнение методов, а не как высокую точность готовой биологической системы.

## Версионирование и воспроизводимость

- ID снимка данных детерминирован содержимым исходных файлов и параметром количества аугментаций.
- `manifest.csv` связывает каждый вариант с исходным изображением и содержит SHA-256 файла.
- `data/raw/butterflies/sources.csv` фиксирует источник, автора, лицензию и SHA-256 каждого загруженного снимка.
- `experiments.jsonl` хранит отдельную запись для каждого сочетания режима данных и модели.
- `results.csv` — табличное представление всей истории.
- В эксперименте сохраняются seed, размер тестовой выборки, список классов, параметры модели, версии библиотек и SHA-256 сериализованной модели.
- Файлы моделей, предсказаний, матриц ошибок и метрик лежат в отдельной папке эксперимента.
- Команда `select --experiment-id <ID>` копирует модель в каталог выбранной версии, а `predict --image <путь>` загружает именно ее.

## Инструкция запуска

Установка зависимостей для Windows 7 и Python 3.8.10:

```bat
py -3.8 -m pip install -r requirements.txt
```

Проверка полного цикла на демонстрационных изображениях:

```bat
py -3.8 main.py demo
py -3.8 main.py history
```

Загрузка реальных фотографий (нужен доступ к Интернету; изображения CC BY 4.0/CC0, исходные файлы и манифест локальные):

```bat
py -3.8 scripts\download_gbif_butterflies.py --images-per-class 50 --max-records 6000
py -3.8 main.py dataset-info --data-dir data/raw/butterflies
py -3.8 main.py run --data-dir data/raw/butterflies --test-size 0.25 --augment-factor 3 --image-size 24 --seed 42
py -3.8 main.py history
```

Чтобы не перезаписать уже загруженные данные, скрипт откажется работать с непустым каталогом назначения. Для повторной загрузки задайте другой путь через `--output-dir`.

После этого выбирают ID эксперимента из списка:

```bat
py -3.8 main.py select --experiment-id <ID_ИЗ_ИСТОРИИ>
py -3.8 main.py predict --image <ПУТЬ_К_ИЗОБРАЖЕНИЮ>
```

Автоматические проверки:

```bat
py -3.8 -m unittest discover -s tests -v
```
